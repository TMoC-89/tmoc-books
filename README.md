# TMoC Books

Static reading site for the TMoC book translations.

- Live site: https://TMoC-89.github.io/tmoc-books/
- Deployment: GitHub Pages via the workflow in `.github/workflows/pages.yml`, from `main`
- Local preview: `python3 -m http.server 8000`

The site has no build step or external runtime dependencies.

Current library: **Heroes Without History**, **Right and Left in Islam**, **Sophia**, **Religion and Socialism**, **Patience and Victory**, **Glossarium**, and Husayn Muruwwa’s four-volume **Materialist Tendencies in Arab-Islamic Philosophy**.


## Materialist Tendencies

The four-volume Muruwwa work uses a work-level landing page at `materialist-tendencies/` and separate bilingual readers at `volume-1/` through `volume-4/`. Each volume provides English and Arabic Markdown downloads; the landing page also provides a ZIP containing all eight Markdown files.
