# Site structure

- One Library card for the complete work.
- One work-level landing page with overview and four volume cards.
- Four separate bilingual reader pages (`volume-1/` … `volume-4/`).
- Persistent I–IV switch in every reader.
- Sidebar uses major headings only: chapter / major section granularity, not every numbered subsection. Bibliography and indexes are kept as single navigational destinations rather than exposing every alphabet letter.
- English / Arabic switch stays within the same structural section.
- Individual Markdown downloads on each reader plus one complete eight-file ZIP on the work landing page.
